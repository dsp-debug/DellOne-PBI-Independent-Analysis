# DellOne — PBI Independent Analysis

> **Dell Analyst Bootcamp (Cohort 1, 2026)**
> FSIO — Zambia

## Assignment Overview

Each AIT selects a topic of their choice and sources a dataset from **reliable and validated sources** (e.g., official statistics portals, reputable research institutions, government databases, or well-established organizations).

**Datasets from platforms such as Kaggle or other user-generated/open repositories (e.g., GitHub) are not permitted**, as they may not meet required reliability and validation standards.

## Key Requirements

- Work must be completed **individually**.
- Choose a topic with **clear practical value or impact**.
- Analysis should demonstrate **practical usefulness** (e.g., insights that could inform decisions, identify trends, or highlight opportunities).
- Use **Power BI** for the analysis.
- High attention to detail (ATD) is mandatory.

## Submission Process

> **All submissions are made via Pull Request on this repository.**

1. Clone this repository to your local machine.
2. Create a new branch named `firstname-lastname` (e.g., `blessings-chinyama`).
3. Create a folder named `Firstname_Lastname` inside the repo root (e.g., `Blessings_Chinyama/`).
4. Add your deliverables to your folder (see below).
5. Commit and push your branch.
6. Open a **Pull Request** targeting `main`.
7. Your PR title should be: `PBI Independent Analysis — [Your Full Name]`

## Deliverables (per AIT)

Place the following files inside your named folder:

| File | Description |
|------|-------------|
| `README.md` | Brief description of your topic, data source(s), and key insights |
| `*.pbix` | Your completed Power BI report |
| `CoverLetter.pdf` | A professionally written cover letter presenting your project, its relevance, and what you sought to uncover from the data — written as you would compose a formal submission email to Ms. Chama, Mr. Spratt, and Dr. Shale |
| `Summary.pdf` | A PDF summarizing your findings, key insights, and conclusions from the analysis |

> ⚠️ **Strict Attention to Detail (ATD) is mandatory.** Your cover letter, file naming, folder structure, commit messages, and PR formatting will all be scrutinized. Sloppy work will not be accepted.
