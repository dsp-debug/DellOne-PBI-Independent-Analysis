DIVORCE RATES IN SOUTH AFRICA

The data analysis looks at divorce rates in South Africa from the year 2021 to 2023.
The divorce data was posted on Data First by Statistics South Africa.
The data analysis answers the question as to whether there is a statistical significant association between female occupations and grounds for divorce.
The data analysis also highlights key insights such as most common grounds for divorce, the female occupation with the highest number of divorce cases and leading plaintiff sex.
